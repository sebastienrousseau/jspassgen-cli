# Getting support

## Read first

- [README.md](README.md): install, the `generate` options and what is
  not available yet.
- [DEVELOPMENT.md](DEVELOPMENT.md): setup, testing and every CI gate.

## Supported versions

The latest release, `0.0.22`, and `main` are supported; older `0.0.x`
versions are not. The CLI follows the jspassgen suite's version.

| Version | Status | Supported |
| :--- | :--- | :--- |
| `0.0.22` | Latest release | Yes |
| `main` | In development | Yes |

## Questions and bugs

Open an [issue](https://github.com/sebastienrousseau/jspassgen-cli/issues/new/choose).
For a bug, include the commit, your Node.js version and operating
system, the command you ran and its output. Never paste a password you
use.

A problem with generated passwords themselves (their alphabet, length or
entropy) belongs in [jspassgen's issues](https://github.com/sebastienrousseau/jspassgen/issues).

## Security

Never report a vulnerability in a public issue; follow
[SECURITY.md](SECURITY.md).

## Response times

The project is maintained in a personal capacity, with no SLA. The goal
is a first answer within a few working days.
